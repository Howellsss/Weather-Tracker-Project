How I built the Weather Tracker :I built this weather app with three files — index.html for structure, styles.css for styling, and script.js for logic. The HTML uses semantic tags like <header>, <main>, and`<section>, and the CSS matches the brief's navy and teal colour scheme with a media query for mobile plus hover effects and transitions. The JavaScript uses the free Open-Meteo API in two async/await steps — geocoding the city name into coordinates, then fetching the current weather and five-day forecast — with error handling for invalid cities, WMO codes mapped to icons, and forecast days generated dynamically so they always match the current date.
